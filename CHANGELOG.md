# Changelog

Every public language release gets its own section here. The versioned language specification is
the final word on syntax and behavior.

## [0.2.0] - 2026-08-27

- Added the bytecode compiler and stack-based VM as the default backend.
- Kept the tree-walking interpreter available with `--interp` for comparison.
- Added projects with `guppty new`, `init`, `run`, `check`, and `build`.
- Added readable, located errors and dual-backend example checks.
