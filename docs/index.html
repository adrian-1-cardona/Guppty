Guppty 0.2.0

Documentation

Guppty is a small indentation-based programming language written in Rust. You write .gup files, and the guppty command compiles them to bytecode and runs them on a stack virtual machine. A tree-walking interpreter is included as a second backend.

This page is the full reference: install the CLI, write .gup programs, and look up every command. Jump from the lists below, or read it through.

Installing Guppty

The install script checks for a Rust toolchain, installs it with rustup if it is missing, builds guppty, and places the binary on your PATH. You only need to run it once.

macOS and Linux

curl -fsSL https://raw.githubusercontent.com/adrian-1-cardona/guppty/main/install.sh | bash

Read install.sh before running it if you would rather know what it does first.

Windows

irm https://raw.githubusercontent.com/adrian-1-cardona/guppty/main/install.ps1 | iex

Run this from PowerShell. It follows the same steps as the shell script: install Rust if needed, then put the guppty command on your PATH. The script is install.ps1.

Just installed Rust? Open a new terminal so that ~/.cargo/bin is on your PATH, then run guppty help to confirm the command is available.

Building from source

You need Git and Rust. Install Rust from rustup.rs, then open a new terminal so that cargo is on your PATH.

macOS and Linux

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
git clone https://github.com/adrian-1-cardona/Guppty.git
cd Guppty
cargo install --path .
guppty examples/program.gup

Windows

winget install Rustlang.Rustup
git clone https://github.com/adrian-1-cardona/Guppty.git
cd Guppty
cargo install --path .
guppty .\examples\program.gup

Cargo installs the binary into ~/.cargo/bin, or C:\Users\You\.cargo\bin on Windows.

Quick start

These four commands take an empty directory to a standalone executable. Commands that are not given a filename read the entry path from guppty.toml.

  1. Create the project. This writes a manifest and a starter source file.

    guppty new hello && cd hello

  2. Check it. Reports errors without running the program.

    guppty check

  3. Run it. Compiles to bytecode and executes it on the virtual machine.

    guppty run

  4. Build it. Packages the runtime and source into a standalone executable.

    guppty build

guppty new lays out the project like this:

hello/
├── guppty.toml
└── src/
    └── main.gup

Downloads

The repository is available as a source ZIP. Unpack it and run cargo install --path . inside the directory; this requires Rust. The install script above is the shorter path if you only want the guppty command.

Prebuilt binaries that do not require Rust are planned for a future release.

All commands accept an optional .gup file path instead of reading the project manifest.

guppty run
Compile and execute the project on the virtual machine.
guppty build

guppty help
List every subcommand and its usage.
--interp
Run through the tree-walking interpreter instead of the virtual machine.

guppty new

Creates a project directory containing a manifest and src/main.gup.

guppty new hello

guppty check

Lexes, parses, and compiles the project without executing it.

guppty check

guppty run

Compiles and executes the project on the virtual machine.

guppty run
guppty hello.gup

guppty build

Builds a standalone executable. Use --output to choose the path.

guppty build
guppty build --output dist/hello

guppty help

Lists every subcommand and its usage.

guppty help

--interp

Runs the program through the tree-walking interpreter instead of the virtual machine. Both backends should produce identical output for correct programs; the flag exists so you can compare them. 

guppty hello.gup --interp

cargo run

When working on Guppty itself, run the compiler without reinstalling the binary.

cargo run -- examples/program.gup

Language reference

Blocks are delimited by indentation; there are no curly braces or semicolons. Use four spaces per level and do not mix tabs and spaces. Variables are created by assignment, with no let or var keyword. The available types are integers, floats, strings, chars, booleans, and arrays. out() prints a value.

Variables and output

x = 5
name = "Guppty"
ready = true
letter = 'g'
out(name)
out(x + 10)

Control flow

Indent the body under the keyword. for loops take a range written as range(1 through 3). 

score = 85
if score >= 80
    out("You passed!")
else
    out("Keep studying!")

for i in range(1 through 3)
    out(i)

Functions

Write the name and parameters on one line, then indent the body. return sends a value back. 

add(a, b)
    return a + b

out(add(2, 3))

Arrays

Put values between square brackets, grab one with a zero-based index, and use len() when you want the size. Arrays can mix and nest values :D 

friends = ["Ada", "Grace", "Linus"]
out(friends[0])
out(len(friends))
nested = [[1, 2], [3, 4]]
out(nested[1][0])

Closures

A function defined inside another function keeps access to the enclosing scope.

makeAdder(x)
    addIt(y)
        return x + y
    return addIt

adder = makeAdder(5)
out(adder(3))

Comments

Everything after // on a line is ignored.

// this is a comment
out(42) // inline comment

Example programs

The examples/ directory contains a runnable program for every language feature. Each one has a matching file in examples/expected/ holding the exact output it should produce, which is how the integration tests work.

Hello world

out("Hello World!")
guppty examples/hello.gup

Recursion

factorial(n)
    if n <= 1
        return 1
    return n * factorial(n - 1)

out(factorial(5))
guppty examples/recursion_factorial.gup

Closure counter

makeCounter(start)
    count = start
    increment()
        count = count + 1
        return count
    return increment
guppty examples/closure_counter.gup

About Guppty

Guppty is not intended to replace Python or Rust. It is meant to be small enough to learn from and pleasant enough to extend. The whole project is a single crate with clearly named files.

The language supports variables, arithmetic, strings, booleans, if/else, while and for loops, functions, recursion, and closures.

It exists to answer a straightforward question: what actually happens when you type text into a file and tell a computer to run it? Keeping the implementation small means you can add a keyword and follow it through the lexer, parser, compiler, and virtual machine in one sitting.

How it works

Guppty is Rust 2021 with no external runtime dependencies. The pipeline is conventional:

  1. source.gup file
  2. lexertokens
  3. parserAST
  4. compilerbytecode
  5. VMstdout

The lexer turns characters into tokens and tracks indentation. The parser builds an abstract syntax tree. The compiler emits bytecode. The virtual machine executes that bytecode on a value stack with call frames. Passing --interp skips compilation and walks the syntax tree directly instead.

Rust 2021
A fast native binary, strong types for tokens, syntax tree, and bytecode, and Cargo for tests and builds. The core uses no external crates.
Stack virtual machine
The default backend. Compiles to bytecode first, then executes it against a value stack and call frames, in the same style as the Java, Python, and Lua virtual machines.
Tree-walking interpreter
The --interp path. Walks the syntax tree node by node. Simpler to follow, and useful as a reference implementation for verifying the compiler.
Integration tests
Run real .gup programs and compare their output against the expected output files, so the documented examples and the test suite are the same thing.

Benchmarks

recursion_fib.gup was run 200 times in release mode and the wall-clock time averaged. The measurement covers startup, file input, lexing, parsing, compilation or interpretation, and execution.

Average wall-clock time over 200 release-mode runs.
Backend Average
Virtual machine (compile and run) 2.69 ms
Tree-walking interpreter (--interp) 2.64 ms

At this size the difference is noise: the program is tiny, so startup and file reading dominate. As programs grow, the virtual machine should pull ahead because it executes precompiled bytecode rather than re-walking the syntax tree on every run.

Contributing

Fork the repository, create a branch, run cargo test, and open a pull request. Keep each pull request focused on one change. If you add a language feature, include an example .gup file and an expected output file so that it becomes a test automatically.

  • Install Guppty, or Rust from rustup.rs.
  • Run cargo test before opening a pull request.
  • Keep syntax keywords in src/syntax.rs.
  • Do not commit the target/ build directory.

Troubleshooting

The installer failed
You need curl on macOS and Linux, or PowerShell on Windows, plus network access. If Rust was just installed, open a new terminal so that ~/.cargo/bin is on your PATH, then try again.
cargo or rustc not found
The install script handles Rust for you. When installing manually, get it from rustup.rs and restart your terminal.
guppty not found after installing
The binary lives in ~/.cargo/bin, or C:\Users\You\.cargo\bin on Windows. Check your PATH, or run source "$HOME/.cargo/env" and try again.
Guppty cannot read my file
Create a project with guppty new my_program, or pass a source path explicitly: guppty ./my_program.gup.
Indentation errors
Do not mix tabs and spaces. Use four spaces per level, as the examples do. A single line at the wrong level will confuse the parser.
Verifying an installation
Run guppty check inside a project, or cargo test from a source checkout.
